# Happy Birthday, Mama ♡

Website kartu ulang tahun sederhana, hangat, dan interaktif.

## Cara buka
Buka `index.html` di browser, atau:

```bash
npx serve .
```

## GitHub Pages
1. Push folder ini ke repository GitHub.
2. Settings → Pages → Deploy from branch (root).

## Fitur
- Layar pembuka lembut
- Heart interaktif + animasi
- Doa / wish acak (Indonesia + English)
- Surat singkat
- Kue + tiup lilin + confetti
- Pesan rahasia di akhir
- Tombol musik ♫ — instrumental lembut dari browser (tanpa file audio)

## Edit konten
- Teks utama → `index.html`
- Daftar wish → `data/wishes.json`

Dibuat dengan penuh sayang ♡
